A5 reviewed `site/scripts/beta-provision-core.mjs`.

### 4. A1 deterministic Worker/D1/R2 pair is unique per instance and reruns predictably — PASS

### 5. A1 establishes/verifies A2 runtime + D1 instance identity before exposure — PASS

The generated beta Worker config contains:

- `APP_ENV=beta`
- `INSTANCE_ID=beta:<instance>`
- `DB_SCHEMA_MODE=migration-only`

For a newly created beta D1, A1:

1. applies numbered migrations;
2. applies existing seeds;
3. explicitly writes:
   - `app_environment=beta`
   - `instance_id=beta:<instance>`

7. verifies the resolved pair again.

For an existing complete pair, A1 verifies the D1 identity **before** running migrations or identity statements, so a wrong/unmarked existing D1 is not auto-claimed.
