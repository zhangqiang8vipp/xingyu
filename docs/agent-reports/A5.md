## A5 changes

### `site/tests/integration/private-beta-safety-contracts.test.mjs`

Adds independent contracts around the existing Worker/MCP/D1 path:

1. Create a private Knowledge Space through the real MCP tool path.
2. Create a draft inside that private space.
3. Verify the anonymous public article URL remains 404.
4. Update the private draft with the correct optimistic version.
5. Attempt a stale update and verify it fails without:
   - overwriting accepted content;
   - incrementing the version;
   - moving the post out of its private space;
   - adding an accepted-write audit receipt.
6. Publish a Knowledge Space post and verify:
   - status can become `published`;
   - visibility remains `space`;
   - anonymous public reading remains 404.
7. Unpublish it and verify version/space continuity.
8. Verify the accepted write trail is exactly create/update/publish/unpublish.
9. Verify the raw legacy MCP bearer token is not persisted in the audit rows.
10. Attempt recursive private-space deletion with the wrong confirmation text and verify the rejected destructive operation is atomic: the space and contained post remain intact and private.
