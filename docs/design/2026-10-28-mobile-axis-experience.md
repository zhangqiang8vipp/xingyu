# XINGYU · Mobile AXIS 移动体验设计规范

**日期：** 2026-10-28　**状态：** Phase A 已合并 `main` 并通过 5 档 Chromium 布局验收；Phase B 代码在独立 PR 验证中。**原则：不新增页面、不引入第二套视觉系统。**

## 1. 风格归属

公开站点继续使用现有 01 AXIS 品牌、悬浮岛导航和杂志式阅读排版。登录后的后台沿用相同材质：半透明玻璃岛、克制的蓝色选中态、冷白灰/深黑背景、细线边界、柔和阴影、留白和原系统字体。禁止为手机单独安装 UI 库或定义新调色板。色彩只用既有 `--admin-*` 变量。

桌面端保持现有侧边导航。手机端不把桌面后台压成窄屏：顶部是品牌与搜索/主题/账户入口，底部只有高频任务导航，详情内容单列，复杂动作收纳进同源 Sheet。公开博客**不加底部导航**。

## 2. 四种主要移动界面

| 场景 | 顶部 | 底部 | 核心任务 |
|---|---|---|---|
| 公开首页、文章、归档 | 保留现有 AXIS 悬浮岛 | 不增加 | 搜索、阅读、分享 |
| 管理后台（个人和站点管理员） | 同源 54px 悬浮岛 | 浏览 · 文章 · 空间 · 更多 | 浏览、编辑、管理知识 |
| AI 连接账号区 | 同源 54px 悬浮岛 | 知识空间 · AI 连接 · 知识问答 · 博客 | 授权、撤销、使用知识 |
| 编辑、历史版本、分享 | 任务自身的标题/关闭/确认 | 不重复显示主导航 | 连续编辑、真实前台预览、单文档授权 |

手机的“更多”包含文件、接入、设置等低频入口。组织管理在实际可用 UI 开放前不应出现一个点击后只跳回后台的菜单项；原 `/organizations`、`/workspace` 兼容路由和权限 API 保留。

## 3. 视觉规格

| 模块 | 规格 |
|---|---|
| 顶岛 | 左右 8px；距顶部 8px 加 `safe-area-inset-top`；高 54px；圆角 18px |
| 底岛 | 左右 10px；最大宽 480px；高 66px；圆角 22px；四等宽入口，单入口高 52px |
| 页面正文 | 左右留白 16px；一级标题 28–34px；辅助描述 ≥12px |
| 常见触控 | 建议 ≥44px 的点击区；选中态蓝色，其他为中性色 |
| Sheet | 宽度不超过 480px，内容可独立滚动，不压住键盘或安全区 |
| 深浅色 | 沿用现有令牌和系统主题；使用 `prefers-reduced-motion` 时降低过渡 |

## 5. 质量门槛

不得出现横向滚动、两行底栏、交叉遮挡。读者、编辑者与站点管理员仍遵守原权限。手机文章与共创预览继续使用同一个真实前台。对浏览器截图和有实测结果的改动才判定视觉验收通过。未验证时必须标注，不允许直接发布到 Cloudflare。
