# XINGYU / 01 AXIS · 人本体验进化

**状态：设计基线已冻结，增量实现待浏览器验收。** 本文不授权上线或合并。

## 不可改变的产品语言

- 以 `main` 当前线上版为基准，保留 01 AXIS 标志、品牌与冷白灰/深黑色系。
- **全局搜索不可删除、降级或隐藏到深层菜单。** 保留 `⌘/Ctrl+K`、键盘结果导航和既有检索 API 的权限边界。
- **顶部与底部悬浮岛不可取消。** 保留手机顶部 54px 的 AXIS 品牌岛与底部 66px 四入口岛；公开博客不添加底部导航。
- 正文继续调用 **原有公开前台阅读器**。编辑预览与共创预览必须使用同一真实渲染流程。
- 源码 / 分屏 / 阅读三模式都要保留，Markdown 编辑器不得用静态 Demo 取代。
- 所有样式沿用 `--admin-*` token，`prefers-reduced-motion` 下减少不必要动效。不要新 UI 库、新调色板、第二套后台。
- 所有权限判断在服务端保留；界面增加入口不等于授予新权限。

## 这一轮已落实的交互优化

| 场景 | 问题 | 新行为 |
|---|---|---|
| 全局搜索 | 个人与公开文章拼接检索可能遗漏结果，错误时显示空列表 | 按范围走权限过滤的统一服务端列表；保留 Cmd/Ctrl+K、箭头和回车；提供错误重试 |
| 搜索浮岛 | 关闭后键盘焦点消失 | Escape、选定结果后返回触发按钮焦点；新增清楚的范围切换 |
| 写作表单 | 直接关闭可能无提示丢失改动 | 只追踪实际编辑字段；未保存离开二次确认，浏览器卸载提醒 |
| 保存 | 连点重复请求，网络异常时没有明确恢复办法 | 并发保存保护，明确“保存中/失败仍保留草稿” |
| 写作模式 | 源码/分屏/阅读入口不在一处 | 在原 Markdown 编辑区给出三种一键入口，仍共用编辑器和真实前台 |
| 沉浸写作 | “完成”让人误会已保存 | 返回操作标明返回表单、需要单独保存 |
| 知识空间 | 卡片只有鼠标可点 | Enter/空格打开空间，目录高亮，返回上级及手机目录加 ARIA |
| 浏览首页 | 技术健康摘要过度占据视觉 | 诊断折叠，杂志式首页继续为视觉主角 |
| 多设备 | 小字/触控和键盘提示不一致 | 增量 CSS：可读字号、44px 手机可点击尺寸、焦点圈与减弱动效 |

## 质量与验收

1. `npm run lint`、`npm run typecheck`、`npm run build` 和完整 `npm run test:source` 通过。
2. 真实 Chromium 检查 320/375/390/430/768px、桌面 1365px：岛不重叠、不溢出，不破坏暗黑主题。
3. 验证搜索范围、快捷键、无结果与请求失败；编辑器未保存退出、网络故障、保存失败与模式切换；空间读者/编辑者/所有者权限。
4. 对照线上视觉审查：**不把产品改成通用 SaaS dashboard**；沿用站点正文、配色和品牌比例。
5. iPhone Safari 原生键盘、横屏、Safe Area 还需人工真机验收，不能用 Chromium 代替。
