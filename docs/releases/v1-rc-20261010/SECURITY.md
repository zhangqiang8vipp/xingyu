# 安全门禁

## 身份

- 永久身份是内部用户 ID。邮箱是登录材料。
- 注册发现邮箱已存在时直接返回，不合并账号，也不透露邮箱是否存在。
- 新密码使用 Workers 上实测可用的原生 scrypt。不要把迭代次数降到 10 万次 PBKDF2 来迁就平台限制。
- 密码、重置链接、OAuth 授权码和刷新令牌不写入日志。发信失败只记录错误名。

## 会话与 CSRF

- 身份 Cookie 为 `xingyu_identity_session`，HttpOnly。
- 登录、注册、重置、退出和工作区写入都核对 `Origin`。
- 密码重置会使该用户尚未撤销的网页会话、MCP access/refresh 和同意记录失效。

## 租户

- 个人工作区只属于所有者。
- 共享工作区只认显式成员和邀请角色。Viewer 不能写。
- 组织成员资格不授予组织工作区权限。
- 团队授权实时计算。成员离开组织、离开团队或授权被删，下一次请求失效。
- 空间 ACL 不能越过工作区角色，也不能越过受限父空间。
- 公开路由只服务工作区 1 的已发布文章。

## MCP

- 令牌绑定 `user:<id>`，并受 scope 限制。
- 旧的全局 `MCP_WRITE_TOKEN` 不能作为生产多用户入口。
- 授权码单次使用。重复使用旧刷新令牌会作废该令牌族。
- 工具调用时再查 `workspace_effective_grants` 和空间 ACL，不信任令牌签发时的成员快照。

## 速率

- 登录按 IP 和账号限流。
- 注册、重发验证信和重置密码使用独立计数。
- 公开阅读使用 `VIEW_RATE_LIMITER`。

## 上线前

- 轮换曾经出现在聊天记录中的 Resend 密钥，并只写入目标 Worker 的 Secret。
- 不要为了让测试通过而关闭触发器、放宽角色或扩大 OAuth scope。
- 预发 Grok 客户端若已登记过本机回调，那个登记只属于预发库，不能复制到生产。
