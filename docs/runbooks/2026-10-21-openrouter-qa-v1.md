# XINGYU 知识库问答 v1 · OpenRouter free 发布说明

## 范围

- 公开网站 `/ask`：只检索站点已发布、非私人空间的文章；登录用户可选私人知识及全部授权知识。
- 对概览类问题选取有代表性的真实文章；针对性问题以 FTS5 + 中文短词搜索定位正文。
- 最多五份有权限的文章证据，来源标题、摘要、原文 URL 由 XINGYU 生成，模型不负责提供链接。
- 仅检索模式不调用模型；私人知识发送到 OpenRouter / 其选择的免费模型提供方前需要明确的用户同意。
- OpenRouter `openrouter/free` 可能切换底层提供方。不可用、超时或额度不足则显示原文证据，不编造答案。
- 没有 AI 对话记忆或自动修改知识库。XINGYU 不主动保存用户问题与模型回复。

## 配额与稳定性

- 使用**已有 Schema 25 `oauth_rate_limits` 表**中的独立 `qa:v1:` 命名空间，不创建数据库表，也不改版本号。
- 访客 AI 模型问答 3 次/日，登录用户 8 次/日；仅检索原文分别为 30/100 次/日。
- 免费模型 API 调用全站合计至多 40 次/日（UTC），每日预算由 SQL 原子 UPSERT 控制，不受并发超支影响。
- 仅 HMAC 后的访客摘要、UTC 时间和次数写入数据库；普通 OAuth 限流记录互不影响。
- 每日定时清理 `qa:v1:` 前缀、创建超过 30 天的记录，不处理普通 OAuth 配额数据。
- 公开请求大小最多 2400 字节，请求源校验、模型 22 秒超时和服务端密钥保护。

## 生产发布前必备

1. **吊销曾在聊天中发送的 OpenRouter Key**，创建新的独立、受限密钥；切勿把任何 Key 放在源代码、GitHub PR、公开讨论或日志。
2. Cloudflare 仪表盘 > Workers & Pages > `xingyu-blog` > Settings > Variables and Secrets，创建 encrypted **Secret** `OPENROUTER_API_KEY`。不能放进 `wrangler.production.jsonc` 的 `vars`。如果使用 Wrangler CLI，注意 `wrangler secret put` 可能立即发布 Worker 版本。
3. 验证 Cloudflare 环境的 `VIEWS_IDENTITY_SECRET`、D1 数据库身份、OAuth/MCP 环境变量仍然一致。
4. **不需要 D1 迁移**：当前 v1 保留 Schema 25，与旧 Worker 兼容。执行现有受控生产工作流，严禁跳过 GitHub CI、生产 opt-in 或 D1 实例验证。
5. 模型 Secret 配置完成后，先以小流量在 `/ask` 验证公开模型回答与来源；私人资料的第三方模型发送需要用户主动同意。

## 端到端验收

- 匿名用户只能看到已发布站点文章；草稿和任何私人空间内容不可检索。
- 甲账号的私人文章无法被乙账号查询；旧管理员密码登录与身份登录都能根据授权查自己的资料。
- 原文检索允许比模型问答更高的每日次数，模型余额不足时返回真实来源，不返回伪造链接。
- `/ask` 在移动端、深色主题可用，问答专用 CSS 不扩大公共站点样式。
- 密钥不存在时返回明确配置错误，网页提示仅检索原文；不会将密钥暴露给前端。
- 真实模型结果只根据检索证据回答；未知证据编号不展示为链接。

## 后续增强

- 更稳健的检索评测与来源覆盖率、中文全文召回、SSE 流式回答和缓存。
- 自定义模型供应商、精细配额、引用质量评测；不做自动 AI 记忆。
